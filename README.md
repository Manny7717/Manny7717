Featured Projects
ModelTally

AI visibility analytics platform for local businesses.

ModelTally tests customer-style queries across multiple AI assistants to determine whether a business is being recommended, how it ranks against local competitors, and what can be improved to increase visibility in AI-driven search.

Tech: Next.js · TypeScript · Supabase · PostgreSQL · AI APIs

Visit ModelTally

BrothTracker

VEX Robotics analytics and scouting platform.

BrothTracker uses the RobotEvents API to track team performance, match history, rankings, awards, and competition statistics.

The goal is to make scouting and team research faster and easier before and during competitions.

Tech: JavaScript · REST APIs · JSON · Data Analysis · Web Development

Lappy

Custom Raspberry Pi AI assistant terminal.

Lappy is a Raspberry Pi 5-based AI terminal with a touchscreen interface, kiosk-mode environment, AI agent integration, and voice interaction.

The project combines embedded hardware, Linux, AI APIs, and full-stack software into a standalone physical assistant.

Tech: Raspberry Pi · Linux · TypeScript · AI APIs · Docker · Embedded Systems

VEX Robotics

Competitive robotics, programming, and engineering.

I work on robot design, programming, testing, autonomous routines, strategy, troubleshooting, and engineering documentation as part of competitive VEX Robotics.

The experience has pushed me to work through real engineering tradeoffs, improve designs through iteration, and solve problems under competition deadlines.

Skills: C++ · Robotics · CAD · Problem Solving · Engineering Design
